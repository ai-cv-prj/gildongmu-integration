# 3차 위험 판단: 공통 ROI와 보도 기반 경고

개인별 신체 폭·머리 높이, 실제 거리, 지면 높이 변화는 사용하지 않는다.
YOLO와 Mask2Former는 전체 화면을 그대로 추론한다. 신호등 코드는 변경하지 않는다.

## 변경한 판단

| 항목 | 3차 동작 |
| --- | --- |
| 진행 ROI | 보이는 보도의 시작 위치에 맞춰 상단 높이 30~65% 조정. 보도 미확인 시 45%. 기본 상단 좌우 40~60%, 하단 2~98% |
| 가까운 영역 | 기존 근접 ROI 유지. 신체 치수와 무관한 공통 화면 좌표 |
| 큰 정적 물체 | 접점 폭을 박스 중앙 50%에서 전체 폭으로 변경. 충분히 큰 물체는 기존 먼 거리 구간이어도 CAUTION 후보 |
| 측면 근접 | 박스 하단이 화면 높이 50% 이상이며 높이 18%·너비 12% 이상인 물체가 경로 밖에 있으면 CAUTION |
| 접근 | TTC와 짧은 이동 예측을 함께 사용. 정적 물체도 영상에서 경로로 들어올 것으로 예상되면 CAUTION 후보 |
| 보도 기반 경고 | YOLO 탐지가 없어도 진행 ROI 안의 보행불가 영역을 별도로 검사. CAUTION만 발생시키며 물체 종류·실제 충돌을 확정하지 않음 |
| 가림·화면 이탈 | 박스가 일부 잘리더라도 최근 1초의 근접 이력을 유지하고, 시야 이탈 후 최대 1초 동안 방향 문구로 표시. 사라진 물체의 박스는 만들지 않음 |
| 클래스 변경 | 같은 물체라는 공간·추적 근거가 충분하고 대응이 유일할 때 경고를 연결. 움직임 이력은 초기화 |
| 겹친 경고 | 같은 클래스의 경고 박스가 IoU 65% 이상이거나 작은 박스의 85% 이상 겹치고 면적 차이가 1.6배 이내일 때 한 표시 단위로 묶음. 모든 탐지와 최고 위험 등급은 유지 |

정적 물체의 기존 높이 구간(65%·88%)은 유지한다. 큰 물체·측면 근접 규칙을 보조적으로 추가한다.
TTC는 박스 확대에서 얻은 근사값이며, 잘린 박스에서는 계산하지 않는다.
공통 설정의 TTC 위험 반영은 켜져 있다. 과거 저장 설정의 재현을 위해 새 기능의 라이브러리 기본값은 꺼져 있으며 현재 inference.yaml에서 명시적으로 켠다.

## 보도 경고

원본 클래스 지도를 작은 분석용 지도(너비 324픽셀)로 줄인 뒤 진행 ROI 안에서 보행불가 연결 영역을 찾는다.
모델 입력과 객체 탐지 범위는 줄이지 않는다.

- 연결 영역이 진행 ROI 면적의 0.3% 이상이고, 4개 높이 구간 중 한 구간의 12% 이상을 차지하면 후보가 된다.
- 후보 관측이 0.2초 지속되면 CAUTION을 표시한다.
- 보도 관측이 크게 변하거나 카메라 관측이 불안정하면 판단 불확실로 표시한다. 영역 대부분이 보행불가이면 장애물 윤곽을 그리지 않고 주변 확인 문구를 표시한다.
- 정상 경로 관측이 0.5초 지속돼야 보도 경고를 해제한다.
- 같은 영역의 객체 경고가 있으면 보도 경고 이벤트의 중복을 억제한다.
- 보도 경고는 detections에 가짜 YOLO 박스를 추가하지 않는다. JSONL의 surface와 source=surface 이벤트로 따로 기록한다.

보행불가 분류가 실제 장애물과 항상 같지는 않다. 초록색 보도도 안전 확인은 아니다.
이 규칙에는 깊이 추정, 바닥 단차 판단, 개인별 신체 모델이 없다.

## ROI 방향 갱신

보도 마스크의 여러 높이에서 보이는 경계로 방향 후보를 만든다.
상단의 더 먼 구간도 사용해, 가까운 보도가 화면을 가득 채웠을 때의 방향 추정 기회를 늘린다.

| 조건 | 처리 |
| --- | --- |
| 시작 | 일관된 방향 후보를 0.2초 확인한 뒤 적용 |
| 현재 방향과 차이 3% 미만 | 유지 |
| 차이 3~8% | 0.5초 확인 후 적용 |
| 차이 8% 이상 | 0.3초 확인 후 적용 |
| 후보가 불안정함 | 확인 시간을 다시 시작 |
| 새 방향을 확인 중 | 기존 경로와 새 후보 경로를 함께 검사 |
| 보도 방향을 잃음 | 0.5초 유지 후 기존 방향과 기본 경로를 함께 검사 |

차이는 화면 너비에 대한 ROI 상단 중심의 이동 비율이다. 실제 회전각이나 사용자의 이동 의도를 뜻하지 않는다.
ROI 재보정 중에도 가까운 물체의 위험 판단은 계속한다.

## 영상 표시와 검증

- 파랑: 진행 ROI, 자홍: 근접 ROI, 노랑: CAUTION 객체·보도 영역.
- 상단 CAUTION 수는 객체 경고에 독립 보도 경고·시야 이탈 안내를 더한 수다. 객체 관측 수와는 다르다.
- surface 필드: 보도 경고, advisories 필드: 현재 보이지 않는 근접 물체에 대한 짧은 문구.
- 116개 자동 테스트 통과. 실제 정확도나 충돌 확률을 뜻하는 수치는 아니다.
- 기존 sample1의 MP4 8개, sample2의 MP4 2개를 전체 프레임 처리한다. MOV는 사용자 요청에 따라 제외한다.
- 실행 설정, 코드 스냅샷, 판정 로그, 프레임 검증 수는 3차 결과 폴더의 manifest.json에 기록한다.
- 영상은 H.264로 저장한다. 인코더가 없는 환경에서는 obs_env의 imageio-ffmpeg 0.6.0을 사용한다.
